# Mi Primer Repositorio

## 1. Descripción breve

Este repositorio fue creado como parte de la práctica de la Unidad 4 del curso de control de versiones.  
Incluye la creación de un repositorio público en GitHub, la organización de carpetas internas y la creación de archivos CSV con datos completos y estructurados.

## 2. Objetivo de la Práctica

- Crear un repositorio público en GitHub.
- Generar y organizar carpetas internas.
- Crear archivos CSV con estructura y datos válidos.
- Documentar correctamente el proyecto utilizando un archivo README.md.

## 3. Contenido del Repositorio

### 3.1. datos_clientes/clientes.csv

Este archivo contiene información detallada de los clientes registrados.  
Las columnas incluidas son:

- `ID_Cliente`: Identificador único del cliente.  
- `Apellido`: Apellido del cliente.  
- `Nombre`: Nombre del cliente.  
- `Email`: Correo electrónico del cliente.  
- `Telefono`: Número de contacto del cliente.  
- `Ciudad`: Ciudad de residencia.  
- `Estatus`: Activo/Inactivo.  
- `Fecha_Registro`: Fecha de registro en el sistema.  
- `Edad`: Edad del cliente.  
- `Cedula`: Número de cédula del cliente.

Actualmente, el archivo contiene **10 clientes** con información completa, lista para análisis o relacionar con ventas.

### 3.2. datos_ventas/ventas.csv

Este archivo contiene registros de ventas realizadas por los clientes.  
Las columnas incluidas son:

- `ID_Venta`: Identificador único de la venta.  
- `ID_Cliente`: Identificador del cliente que realizó la compra.  
- `Fecha`: Fecha en que se realizó la transacción.  
- `Producto`: Nombre del producto vendido.  
- `Cantidad`: Cantidad de unidades adquiridas.  
- `Precio_Unitario`: Precio por unidad del producto (en dólares, `$`).  
- `Monto_Total`: Total de la venta (Cantidad × Precio_Unitario, en `$`).

Actualmente, el archivo contiene **15 ventas** asociadas a los clientes del repositorio. Los precios están expresados en dólares para mayor claridad.
